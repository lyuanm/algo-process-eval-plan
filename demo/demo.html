① 题目 · P047 最短路径（Dijkstra，hard）

给定无向带权图（边权非负），求从源点 src 到所有节点的最短距离；不可达输出 -1。节点 1..n。

测试数据（其一）：4 4 1 / 1 2 1 / 1 3 4 / 2 3 2 / 3 4 1 → 期望 0 1 3 4

② Hy3 解题过程（节选）

思路：最短路径用 Dijkstra 堆优化：优先队列按距离松弛邻边。

复杂度分析：时间复杂度 O((V+E) log V)。

边界与处理：不可达节点输出 -1。

import sys
from collections import deque
def solve():
    data = sys.stdin.read().split()
    n = int(data[0]); m = int(data[1]); src = int(data[2])
    g = [[] for _ in range(n + 1)]; idx = 3
    for _ in range(m):
        u = int(data[idx]); v = int(data[idx+1]); w = int(data[idx+2]); idx += 3
        g[u].append(v); g[v].append(u)
    dist = [-1] * (n + 1); dist[src] = 0
    q = deque([src])
    while q:                       # 误：用无权 BFS 代替带权 Dijkstra
        u = q.popleft()
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    print(" ".join(str(dist[i]) for i in range(1, n + 1)))
solve()
